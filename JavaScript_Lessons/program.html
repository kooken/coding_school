JavaScript Intro — Hello World

How to run JavaScript and display output

Where Does JavaScript Run?

JavaScript runs in the browser. You can include it in an HTML page using the <script> tag.

<!-- At the end of <body> — script loads after the HTML -->
<body>
  <p>Hello!</p>
  <script src="program.js"></script>
</body>

<!-- Or inline -->
<script>
  console.log('Hello from an inline script!');
</script>

console.log()

The most common way to output data while writing JavaScript is console.log(). Output appears in the browser's Developer Tools console. 

console.log('Hello, World!');   // string output
console.log(42);                // number output
console.log(true);              // boolean output
console.log([1, 2, 3]);        // array output
Open Developer Tools with F12 (Windows/Linux) or Cmd+Option+I (Mac), then click the Console tab to see console.log output. This page logs a message — open the console to see it!

document.write()

document.write() inserts text directly into the HTML page. It is rarely used in modern development but useful for understanding how JavaScript interacts with the DOM. 

document.write('<p>Hello from JavaScript!</p>');
