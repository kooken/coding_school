HTML Lesson 2 — Forms

Collecting user input with forms and input elements

The <form> Element

A <form> is a container for interactive controls. When submitted, it sends the collected data to a server (or handles it with JavaScript). 

<form action="/submit" method="post">
  <!-- input elements go here -->
  <button type="submit">Submit</button>
</form>
Attribute Purpose
action URL that receives the form data when submitted
method get (data in URL) or post (data in request body)

<label>

Always pair inputs with a <label>. When a user clicks the label, focus moves to the input. Link them with matching for and id values. 

<label for="username">Username</label>
<input type="text" id="username" name="username">

Text Inputs

The <input> tag is self-closing and changes behavior based on its type attribute.

Checkbox and Radio

<!-- Checkbox: multiple selections allowed -->
<input type="checkbox" id="agree" name="agree">
<label for="agree">I agree to the terms</label>

<!-- Radio: only one selection per group (same name) -->
<input type="radio" id="js" name="language" value="js">
<label for="js">JavaScript</label>

<input type="radio" id="py" name="language" value="py">
<label for="py">Python</label>

<select> and <option>

A dropdown list lets users pick one (or more) options from a list.

<label for="country">Country</label>
<select id="country" name="country">
  <option value="">-- Choose --</option>
  <option value="us">United States</option>
  <option value="uk">United Kingdom</option>
  <option value="de">Germany</option>
</select>

<textarea>

For multi-line text input. Use rows and cols to set its default size.

<label for="message">Message</label>
<textarea id="message" name="message" rows="4" placeholder="Type here..."></textarea>

Built-in Validation

HTML provides attributes that enforce rules before the form can be submitted — no JavaScript needed.

Attribute Effect
required Field must be filled in before submission
minlength / maxlength Minimum / maximum number of characters
min / max Minimum / maximum value for number or date inputs
pattern Regular expression the value must match
placeholder Hint text shown when the field is empty

Try submitting the form above with an empty field or an invalid email to see browser validation in action.
