HTML Lesson 1 — Core Tags

Formatting, links, images, audio, video, and tables

Text Formatting

HTML provides tags to change the meaning and appearance of text inline.

  • Bold / important: <strong> — semantically important text
  • Bold / visual only: <b> — visually bold, no extra meaning
  • Italic / emphasis: <em> — stressed or emphasized text
  • Italic / visual only: <i> — visually italic, no extra meaning
  • Inline code: <code> — console.log('hi')
  • Line break: <br> — forces a new line without starting a new paragraph

div and span

<div> is a block-level container — it takes up the full width and starts on a new line.
<span> is an inline container — it sits within a line of text.

This paragraph is inside a <div> block.

Use span to style part of a sentence without breaking the line.

Links

The <a> (anchor) tag creates hyperlinks. The href attribute holds the destination URL.

<a href="https://www.example.com">Visit Example</a>

<!-- Open in a new tab -->
<a href="https://www.example.com" target="_blank" rel="noopener noreferrer">
  Open in new tab
</a>

Images

The <img> tag embeds an image. It is a self-closing tag — it has no closing </img>. The alt attribute is required for accessibility and shown when the image cannot load. 

<img src="photo.jpg" alt="A description of the image" width="300">

Audio

The <audio> tag embeds a sound file. The controls attribute adds the browser's built-in player.

<audio controls>
  <source src="sound.mp3" type="audio/mpeg">
  Your browser does not support the <audio> element.
</audio>

Video

The <video> tag embeds a video clip. Use width and height to set its size.

<video width="480" height="270" controls>
  <source src="clip.mp4" type="video/mp4">
  Your browser does not support the <video> element.
</video>

Tables

Tables are for displaying data in rows and columns. Use <th> for header cells and <td> for data cells. 

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>30</td>
  </tr>
</table>
Name Age City
Johnny Silverhand 38 Night City
Vi 28 Night City
Judy Alvarez 24 Night City
Avoid using the deprecated border="1" attribute on tables. Apply borders through CSS instead.
