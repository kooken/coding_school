HTML Lesson 3 — Semantic HTML

Using meaningful tags that describe the role of content

Why It Matters

Before HTML5, developers used <div> for everything. Semantic elements replace generic <div> tags with names that describe what the content is, not just how it looks.

Benefit How semantic HTML helps
Accessibility Screen readers announce the role of each region to visually impaired users
SEO Search engines understand which content is navigation, articles, or footers
Maintainability Code is easier to read — <nav> is clearer than <div class="nav">

Page-Level Semantic Elements

Element Purpose
<header> Site or section header — logo, site title, top navigation
<nav> Primary navigation links
<main> The main content of the page — unique to this page, use once
<aside> Supplementary content — sidebar, related links, pull quotes
<footer> Bottom of the page or section — copyright, contact, links

Content Semantic Elements

Element Purpose
<article> Self-contained piece of content that makes sense on its own (blog post, news story, comment)
<section> Thematic grouping of content, usually with a heading
<figure> Self-contained media (image, chart, code) with an optional caption
<figcaption> Caption for the <figure> element
<time> A date/time value; datetime attribute provides machine-readable format
<address> Contact information for the nearest <article> or the whole document

Code Structure

<body>
  <header>
    <h1>My Blog</h1>
    <nav>
      <a href="/">Home</a>
      <a href="/about">About</a>
    </nav>
  </header>

  <main>
    <section>
      <h2>Latest Posts</h2>

      <article>
        <h3>Post Title</h3>
        <time datetime="2025-03-01">March 1, 2025</time>
        <p>Post content…</p>
      </article>
    </section>
  </main>

  <aside>
    <h2>Related Links</h2>
  </aside>

  <footer>
    <p>&copy; 2025 My Blog</p>
    <address>Contact: <a href="mailto:hi@example.com">hi@example.com</a></address>
  </footer>
</body>

Use <div> when no semantic element fits — for layout containers that have no inherent meaning. Use semantic elements whenever the role of the content is clear.
