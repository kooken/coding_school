HTML Intro — Document Structure

How every HTML page is built and the most common elements

The Basic Skeleton

Every HTML document follows this structure:

<!DOCTYPE html>          <!-- tells the browser this is HTML5 -->
<html lang="en">         <!-- root element; lang sets the language -->
<head>
  <meta charset="UTF-8"> <!-- character encoding -->
  <title>Page Title</title>
</head>
<body>
  <!-- visible page content goes here -->
</body>
</html>

Headings

HTML has six heading levels. <h1> is the most important (use once per page as the main title). Use them in order — don't jump from <h1> to <h4>.

Paragraphs

The <p> tag creates a paragraph. Browsers automatically add spacing above and below.

Each paragraph starts on a new line, even when adjacent in the source.

Lists

Unordered list <ul> — for items without a specific order:

  • HTML
  • CSS
  • JavaScript

Ordered list <ol> — for steps or ranked items:

  1. Open a text editor
  2. Write your HTML
  3. Save the file with a .html extension
  4. Open it in a browser

Attributes

Attributes add extra information to an element. They are written inside the opening tag: <tag attribute="value">

Attribute Purpose Example
id Unique identifier for one element id="main-nav"
class Groups elements for CSS styling class="highlight"
title Tooltip text shown on hover title="More info"
lang Declares the element's language lang="en"
